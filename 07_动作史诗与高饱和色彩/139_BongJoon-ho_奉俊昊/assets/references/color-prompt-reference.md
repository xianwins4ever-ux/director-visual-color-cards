## 导演风格执行手册

- 视觉定义：看似自然的家居色逐步被冷绿、地下灰和危险红污染。
- 光线：阶级空间采用不同曝光和色温；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：垂直层级构图、平滑跟移、突然类型转折；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：自然起步，危机时压黑并偏绿；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：全程阴冷、夸张漫画色、阶层空间同质化、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。
