# 导演视觉风格色卡 · 200 位

> 200 位世界导演的视觉风格，每人一个文件夹。
> **你用哪个模型，就打开哪个文件，整段复制，改一个词。**

---

## 这是干什么的

你想让 AI 生成一张"像某位导演拍的"图或视频，但不知道该怎么描述。

这个仓库就是答案。

200 位导演，每位给了：

| 东西 | 在哪 | 有什么用 |
|---|---|---|
| **四套提示词** | `prompts/` | Midjourney / 香蕉·GPT-Image / 视频 / Stable Diffusion，各一份 |
| **色卡** | `色卡主文档.md` | 10 个颜色，带色名 + HEX + 占比 |
| **光影特征** | `色卡主文档.md` | 光从哪来、多硬、什么色温 |
| **关键词** | `色卡主文档.md` | 构图、色彩、情绪的词 |
| **经典场景** | `色卡主文档.md` | 几个可以直接抄的画面设定 |
| **原片剧照** | `assets/film_stills/` | 真实电影截图，用来看"到底长什么样" |
| **影调色卡图** | `assets/color_palettes/` | 3072×1728 的参考图，可以直接喂给视频模型 |

**不需要装任何东西，不需要 API，纯文本 + 图片。**

## 怎么用（三步）

### 1. 找到导演

文件夹名格式：`编号_英文名_中文名`

```
01_黑色悬疑与冷调惊悚/
  ├─ 001_AlfredHitchcock_希区柯克/
  ├─ 002_DavidFincher_大卫·芬奇/
  └─ ...
```

不知道编号？看 [`references/卷内速查表_001-200.md`](references/卷内速查表_001-200.md)，里面是编号 / 导演 / 国籍 / 代表作 / 风格关键词。

**只记得画面感觉也行**：

| 你的描述 | 对应导演 |
|---|---|
| 湿漉漉的红绿霓虹、玻璃上有反光 | 王家卫 |
| 大片的黄沙、人特别小 | 维伦纽瓦 |
| 冷白、克制、没有情绪 | 哈内克 |
| 暗绿黄、病态色调 | 大卫·芬奇 |

### 2. 看你用什么工具

| 你用什么 | 打开这个文件 |
|---|---|
| **Midjourney** | `prompts/midjourney_prompts.md` |
| **香蕉 / ChatGPT 生图** | `prompts/conversational_prompts.md` |
| **Seedance 2.5 / 2.0 / 海螺 H3 / 可灵** | `prompts/video_prompts.md` |
| **Runway / Pika** | `prompts/video_prompts.md`（§三 镜头模板） |
| **Stable Diffusion / ComfyUI** | `prompts/stable_diffusion_prompts.md` |

五套写的是**同一个导演的风格**，随便哪份都行 —— **你用哪个工具就开哪份**。

### 3. 整段复制，改一个词

每份提示词里都有一个 `［主体］` 占位符。把它换成你要画的东西，**后面那段风格照抄别动**。

---

## 唯一要动脑的地方：「［主体］」怎么写

主角要写细，风格要照抄。

| 别这么写 | 这么写 |
|---|---|
| 一个女孩 | 一个穿深绿色套装的女性，站在昏暗走廊尽头，回头看镜头 |
| 一杯咖啡 | 一只白瓷杯放在湿石台上，杯壁挂着水珠，侧逆光 |
| 一片森林 | 雨后的松林，地面苔藓反着光，雾气从树根往上升 |

## 色卡怎么用（这条最值钱）

每位导演给 10 个色。**不要全用上。**

| 角色 | 用几个 | 占多少 | 干嘛的 |
|---|---|---|---|
| 主色 | 1 个 | 40–60% | 定调子 |
| 辅色 | 1–2 个 | 20–30% | 撑层次 |
| 点缀色 / 情绪色 | 1 个 | 约 5% | 提亮用 |

写进提示词要给**色名 + 色值 + 占比**三样：

> 深夜暗蓝 `#1A2332` 占 40% 打底，雾霭钢蓝 `#3D5A6C` 作辅，血暗红 `#7B241C` 只做点缀

**整组画面锁同一组色卡** —— 这是"像同一个导演拍的"的关键。

---

## 出图不像怎么办

**别改风格那段，换一个场景再来一次。** 每位导演都给了好几个经典场景，总有一个对味。

另外两条：

- 同一条提示词**先跑 4 张**再判断
- 调的时候**一次只改一个词**

## 各模型的格式要求（容易被忽略的坑）

| 模型 | 必须满足 |
|---|---|
| **Midjourney** | 逗号标签完整；**结尾参数一起给**（`--ar` `--style raw` `--s` `--v`）；负面提示词也带上 |
| **香蕉 / GPT-Image** | **不能出现任何 `--` 参数**；是完整中文句子，不是标签堆；**不能有否定句** |
| **Seedance 2.5** | 五段齐全（总控 / 参考素材职责 / 首帧完整状态 / 连续时间轴 / 场景特定限制）；**≤30 秒**；时间段**连续不重叠**；切镜要重写新机位、**禁写「同上」**；对白先算 **72–84 字/30 秒**容量，**不许加速硬塞** |
| **Seedance 2.0** | 主体 → 动作 → 运镜 → 风格灯光 → 约束；**一个镜头只写 1 种运镜**；动作写到肢体 + 幅度 + 速度；**负面词必给** |
| **MiniMax H3** | 三段结构（参考素材说明 / 核心创意 / 分段过程描述）；**带时间戳**；**必须有 `overall_soundscape`** |
| **Stable Diffusion** | 正向 + 反向**分别给**，不能混在一起 |
| **Runway / Pika** | 镜头模板整段给；**运镜和节奏不能删** |

## 版本说明 · v1.0（本仓库整理版）

### 相比散装原始版本，这一版做了什么

**1. 200 位导演整合成一个库，不用再来回切**

原来是一份一份单独的包，找导演要翻好几个地方。现在是 10 个色系 × 20 位，一条线走到底，编号连续 001–200。

**2. 每位导演补齐了四套提示词**

不是"一份提示词套所有模型"，而是按每个模型的实际语法分别写：

- Midjourney 带完整参数尾巴
- 香蕉 / GPT-Image 是中文完整句、无 `--`、无否定句
- 视频那份一个文件塞了 **Seedance 2.5 / 2.0 / MiniMax H3 / Runway·Pika 四套规则**，用哪套抄哪段
- Stable Diffusion 正反向分开

**3. 色卡补了占比，不只是列颜色**

10 个色给了色名 + HEX + **建议占比**（主色 40–60% / 辅色 20–30% / 点缀 5%）。照着配比调，画面才不会花。

**4. 每位导演补了"经典场景"**

出图不像的时候，换个场景再来一次，比改风格描述有效。所以每人给了好几个可直接抄的画面设定。

**5. 配了真实电影剧照和影调色卡图**

- `film_stills/`：真实原片截图，用来校准"这个导演到底长什么样"
- `color_palettes/`：3072×1728 的影调色卡，可以直接当视频模型的首帧参考图

剧照来源全部记录在每位导演的 `_film_stills_source.md` 里（FilmGrab / TMDB）。

**6. 加了自检清单**

SKILL.md 里有一张表，逐模型列了"吐出来的提示词必须满足什么"。用来防止最常见的翻车：MJ 忘了带参数、香蕉那份写了 `--`、视频那份时间轴重叠。

**7. 修了 350 条失效的剧照引用**

原始库里文档写的文件名和实际文件对不上（`03_funny_games_lake.jpg` vs 实际的 `05_funny_games.jpg`），点开是裂图。这一版按 `_film_stills_source.md` 里的片名表重新映射，能对上的 222 条改指向正确文件，对不上的 128 条降级为文字标注。现在全库 288 条图片引用**全部有效**。

**8. 图片压缩到 1/3，图库才装得进 Git**

原库 1.4 GB，其中 302 MB 是内嵌 base64 的 HTML、749 MB 是 JPG。这一版：

- JPG 最长边压到 1280，质量 78
- PNG 转 JPG，最长边 1920，质量 88
- 去掉重复内嵌的 HTML

**1.4 GB → 319 MB**，单文件最大 0.5 MB，可以直接 clone，不需要 Git LFS。

## 用 AI Agent 跑

仓库根目录的 `SKILL.md` 是给 agent 看的说明书。放进 `~/.agents/skills/` 就能被自动识别：

```bash
git clone <本仓库地址> ~/.agents/skills/director-visual-color-cards
```

之后直接说：

> 帮我写一段王家卫风格的 Midjourney 提示词，画一个雨夜便利店

agent 会自己找到 200 号王家卫、打开 MJ 那份、把主体替换掉。
