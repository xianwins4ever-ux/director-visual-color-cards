## 六、参数速查

| 效果 | 参数 |
|------|------|
| 迷幻电影感最强 | `--s 850 --style raw --v 6` |
| 更写实/英国社会现实主义 | `--s 500 --style raw --v 6` |
| 更迷幻/超现实 | `--s 950 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 超宽银幕 | `--ar 2.35:1` |
| 迷幻脏绿更重 | 提示词中加 `sickly green, psychedelic, drug haze, purple-blue tint` |
| 孟买暖黄 | 提示词中加 `golden sunlight, warm yellow, vibrant Indian colors, saffron and pink` |
| 末日冷绿 | 提示词中加 `cold green-gray, desaturated, abandoned, eerie empty, post-apocalyptic` |
