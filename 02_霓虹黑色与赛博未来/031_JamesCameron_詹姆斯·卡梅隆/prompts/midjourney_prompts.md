## 六、参数速查

| 效果 | 参数 |
|------|------|
| 史诗大片感最强 | `--s 850 --style raw --v 6` |
| 更写实/更低干预 | `--s 400 --style raw --v 6` |
| 阿凡达荧光效果 | `--s 900 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 超宽史诗 | `--ar 21:9` 或 `--ar 2.35:1` |
| 肖像竖版 | `--ar 3:4` |
| 冷蓝钢强化 | 提示词中加 `cold blue-steel lighting, chrome reflections, metallic blue tones` |
| 火焰爆炸强化 | 提示词中加 `orange fireballs, explosions, sparks, molten metal, fire glow` |
