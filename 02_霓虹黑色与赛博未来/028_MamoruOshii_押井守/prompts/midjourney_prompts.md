## 六、参数速查

| 效果 | 参数 |
|------|------|
| 赛博朋克电影感最强 | `--s 750 --style raw --v 6` |
| 更写实动画/更低干预 | `--s 250 --style raw --v 6` |
| 更艺术化/风格化 | `--s 900 --v 6 --niji 6` |
| 宽银幕电影 | `--ar 16:9` |
| 超宽赛博全景 | `--ar 21:9` |
| 肖像竖版 | `--ar 3:4` |
| 雨夜冷调强化 | 提示词中加 `heavy rain, wet reflections, cold blue-grey palette, overcast` |
| 数据绿强化 | 提示词中加 `data green glow, green terminal light, matrix green code` |
