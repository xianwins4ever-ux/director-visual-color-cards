## 六、参数速查

| 效果 | 参数 |
|------|------|
| 电影感最强 | `--s 750 --style raw --v 6` |
| 更写实/低预算感 | `--s 250 --style raw --v 6` |
| 更艺术化/氛围 | `--s 900 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 超宽银幕 | `--ar 2.35:1` |
| 冷调更重 | 提示词中加 `desaturated, cool blue tint, steel gray tones` |
| 暖橙点缀 | 提示词中加 `warm amber warning lights, orange accent glow` |
