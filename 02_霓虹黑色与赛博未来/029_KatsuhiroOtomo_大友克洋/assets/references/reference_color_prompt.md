- 视觉定义：巨型都市基础设施与失控身体能量以方向明确的高速运动冲撞

- 构图与摄影：低机位广角、摩托道路轴线和巨大建筑尺度
- 调色与材质：城市黑、尾灯红、军绿、实验室白和能量青蓝；局部强调色不污染整幅画面。
