## 六、参数速查

| 效果 | 参数 |
|------|------|
| 爆炸/动作最强 | `--s 900 --style raw --v 6` |
| 更写实动画 | `--s 500 --style raw --v 6` |
| 80年代动画风格 | `--s 750 --niji 6` |
| 宽银幕电影 | `--ar 16:9` |
| 超宽史诗全景 | `--ar 21:9` |
| 肖像竖版 | `--ar 3:4` |
| 爆炸橙红强化 | 提示词中加 `explosive orange-red, fireball, nuclear glow, high saturation` |
| 废墟末日感 | 提示词中加 `grey-brown ruins, crumbled concrete, dust smoke, post-apocalyptic` |
