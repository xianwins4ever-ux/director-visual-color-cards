## 六、参数速查

| 效果 | 参数 |
|------|------|
| 史诗暗调最强 | `--s 900 --style raw --v 6` |
| 更写实/更低干预 | `--s 400 --style raw --v 6` |
| 300油画风 | `--s 950 --v 6` |
| 宽银幕史诗 | `--ar 2.35:1` |
| IMAX比例 | `--ar 16:9` 或 `--ar 1.43:1` |
| 肖像竖版 | `--ar 3:4` 或 `--ar 2:3` |
| 暗金强化 | 提示词中加 `dark gold bronze, sepia tones, oil painting texture, desaturated warm tones` |
| 闪电白强化 | 提示词中加 `lightning white highlights, bright white rim light, electric sparks, slow motion droplets` |
