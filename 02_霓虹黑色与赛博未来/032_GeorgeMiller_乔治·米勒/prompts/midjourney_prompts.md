## 六、参数速查

| 效果 | 参数 |
|------|------|
| 废土动作感最强 | `--s 900 --style raw --v 6` |
| 更写实/更低干预 | `--s 400 --style raw --v 6` |
| 电影宽银幕 | `--ar 2.35:1` |
| 标准宽屏 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| IMAX竖版 | `--ar 9:16` |
| 沙漠橙强化 | 提示词中加 `saturated orange desert, blazing orange sun, ochre sand, orange-tinted sky` |
| 烈焰红强化 | 提示词中加 `blazing red fire, explosions, flame thrower, fire and blood` |
