# 乔治·米勒电影综合色卡｜可复制色卡 Prompt

色彩依据：乔治·米勒 / George Miller 的真实电影截图取色。

## 导演风格执行手册

- 视觉定义：橙红荒漠与深青天空在超高对比中驱动持续动作。
- 光线：强烈日光、沙尘、火焰、夜间冷光；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：中心化动作、快速但清晰的运动链；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：橙青强分离但保持材质，黑位清楚；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：动作模糊成团、糖果霓虹、无沙尘层次、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。

## Seedance 2.0 执行块

严格按上述 HEX 的综合色彩关系执行：先由真实场景材质和光源建立主辅色比例，再让人物服装、道具与反射承担连接色和强调色。曝光保留高光纹理，黑位有细节，肤色中性可读；不要用全局滤镜替代美术、灯光和材质。镜头运动必须由人物动作、视线或环境变化触发，并在新的颜色或空间状态上明确停止。

Avoid：任意新增综合色、全局青橙、统一高饱和、肤色被染色、死黑、爆白、塑料材质、无动机环绕、随机变焦、生成式文字和伪造电影截图。
