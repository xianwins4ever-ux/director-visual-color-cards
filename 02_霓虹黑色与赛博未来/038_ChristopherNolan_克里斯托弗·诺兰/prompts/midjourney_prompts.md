## 六、参数速查

| 效果 | 参数 |
|------|------|
| IMAX电影感最强 | `--s 800 --style raw --v 6` |
| 更写实/实拍感 | `--s 500 --style raw --v 6` |
| 更史诗/艺术化 | `--s 950 --v 6` |
| IMAX宽银幕 | `--ar 2.35:1` |
| 标准宽银幕 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 冷蓝现实层 | 提示词中加 `cold steel blue, architectural gray, concrete, corporate` |
| 暖金梦境层 | 提示词中加 `warm amber light, golden tones, wood interiors, nostalgic` |
