## 导演风格执行手册

- 视觉定义：冷钢蓝、沙褐和高反差黑白把时间与机械结构视觉化。
- 光线：大尺度自然光、实景火光、冷室内光；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：IMAX尺度远景、稳定推进、平行剪辑；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：低饱和冷中性，暖色用于时间压力；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：全局青橙、晃动动作、科幻霓虹泛滥、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。
