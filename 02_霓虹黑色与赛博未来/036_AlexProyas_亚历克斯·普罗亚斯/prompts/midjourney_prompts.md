## 六、参数速查

| 效果 | 参数 |
|------|------|
| 电影感最强 | `--s 800 --style raw --v 6` |
| 更漫画/高对比 | `--s 950 --v 6` |
| 更写实/黑色电影 | `--s 500 --style raw --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 超宽银幕 | `--ar 2.35:1` |
| 哥特暗黑更重 | 提示词中加 `extremely dark, deep shadows, pitch black, noir lighting` |
| 血红强调 | 提示词中加 `blood red accents, crimson lighting, red neon glow` |
