## 六、参数速查

| 效果 | 参数 |
|------|------|
| 80年代动作感最强 | `--s 750 --style raw --v 6` |
| 更写实/军事感 | `--s 500 --style raw --v 6` |
| 更戏剧/史诗 | `--s 900 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 超宽动作 | `--ar 2.35:1` |
| 钢蓝更重 | 提示词中加 `steel blue, cold fluorescent, night interior, smoke` |
| 丛林暗绿 | 提示词中加 `dark green jungle, military khaki, foliage, mud camouflage` |
| 爆炸暖橙 | 提示词中加 `orange fire explosion, backlight silhouette, muzzle flash, fire glow` |
