## 六、参数速查

| 效果 | 参数 |
|------|------|
| 纪实电影感最强 | `--s 750 --style raw --v 6` |
| 更粗粝/纪录片感 | `--s 500 --style raw --v 6` |
| 更科幻/概念艺术 | `--s 900 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 超宽银幕 | `--ar 2.35:1` |
| 脏橙更重 | 提示词中加 `dirty orange, rust, corrugated iron, dust` |
| 夜间警灯 | 提示词中加 `red and blue police lights flashing, night time, neon` |
