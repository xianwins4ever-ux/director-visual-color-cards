## 六、参数速查

| 效果 | 参数 |
|------|------|
| 极简科幻感最强 | `--s 700 --style raw --v 6` |
| 更写实/更低干预 | `--s 300 --style raw --v 6` |
| 虹彩/湮灭效果 | `--s 850 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| 走廊纵深 | `--ar 2.35:1` |
| 冷白强化 | 提示词中加 `sterile white, cold fluorescent, concrete, glass, minimal` |
| 自然变异强化 | 提示词中加 `iridescent, prismatic, shimmering, mutated flora, crystalline` |
