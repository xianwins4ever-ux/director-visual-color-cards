## 六、参数速查

| 效果 | 参数 |
|------|------|
| 罪城漫画感最强 | `--s 850 --style raw --v 6` |
| 更写实/更低干预 | `--s 400 --style raw --v 6` |
| 赛博霓虹效果 | `--s 900 --v 6 --niji 6` |
| 宽银幕漫画 | `--ar 16:9` |
| 超宽罪城 | `--ar 21:9` |
| 肖像竖版 | `--ar 3:4` 或 `--ar 2:3` |
| 纯黑白罪城 | 提示词中加 `extreme high contrast black and white, pure ink black, stark white, no color except red` |
| 霓虹赛博强化 | 提示词中加 `neon magenta, neon cyan, holographic, digital glow, cyberpunk city` |
