## 导演风格执行手册

- 视觉定义：一部电影锁定一套象征色，高纯度色块支配空间与人群。
- 光线：方向明确的自然光与仪式性顶光；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：对称大全景、舞蹈式群体调度；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：主色纯度高，背景压低，材质丝绸化；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：多主色抢戏、随机霓虹、脏灰肤色、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。
