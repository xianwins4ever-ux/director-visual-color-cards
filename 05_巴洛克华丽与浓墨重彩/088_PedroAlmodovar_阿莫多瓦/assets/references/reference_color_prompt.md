## 导演风格执行手册

- 视觉定义：番茄红、孔雀蓝、柠檬黄与暖肤色让情感直接占领空间。
- 光线：明亮室内光、阳光、彩色墙面反射；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：正面构图、流畅跟随、物件特写；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：饱满暖色，肤色健康，黑位柔和；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：脏灰压色、青橙大片感、冷淡极简、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。
