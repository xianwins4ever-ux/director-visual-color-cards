## 导演风格执行手册

- 视觉定义：室内暗金、丝绸花色和远景自然色形成历史的静谧层次。
- 光线：油灯、窗光与林间漫射光；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：固定或极缓移动，深景多层调度；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：低亮度暖金，彩色压在织物中；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：鲜亮宫斗色、快速推拉、扁平棚光、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。
