# 韦斯·安德森电影综合色卡｜可复制色卡 Prompt

色彩依据：韦斯·安德森 / Wes Anderson 的真实电影截图取色。

## 导演风格执行手册

- 视觉定义：对称空间以粉、蓝、黄和红构成精确的童话式秩序。
- 光线：柔和均匀光、平面色块；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：严格对称、横向平移、俯拍物件；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：粉彩中等饱和，阴影柔和，色块边界清楚；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：随意手持、青橙大片感、杂乱背景、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。
