# 今敏电影综合色卡｜可复制色卡 Prompt

色彩依据：今敏 / Satoshi Kon 的真实电影截图取色。

## 导演风格执行手册

- 视觉定义：现实与幻觉用红蓝紫互穿，颜色在剪辑中承担身份错位。
- 光线：舞台光、屏幕光与现实中性光切换；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：主观视点、匹配剪辑、空间突然变形；先交代颜色承载的空间，再进入人物与关键物件。
- 调色与材质：保持红紫纯度，现实段落偏冷中性；高光、中间调和阴影分别处理，局部强调色不污染全画面。
- 禁止跑偏：随机赛博色、无因果闪烁、全程梦幻柔焦、无动机环绕和随机变焦、用统一滤镜替代色彩比例、光源和材质。。

## Seedance 2.0 执行块

严格按上述 HEX 的综合色彩关系执行：先由真实场景材质和光源建立主辅色比例，再让人物服装、道具与反射承担连接色和强调色。曝光保留高光纹理，黑位有细节，肤色中性可读；不要用全局滤镜替代美术、灯光和材质。镜头运动必须由人物动作、视线或环境变化触发，并在新的颜色或空间状态上明确停止。

Avoid：任意新增综合色、全局青橙、统一高饱和、肤色被染色、死黑、爆白、塑料材质、无动机环绕、随机变焦、生成式文字和伪造电影截图。
