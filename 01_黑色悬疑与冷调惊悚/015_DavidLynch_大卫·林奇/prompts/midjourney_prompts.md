# Midjourney 提示词模板 — David Lynch 大卫·林奇风格

> 使用方法：将 `[SUBJECT]` 替换为你的主体描述，按需调整参数

---

## 一、通用风格标签（Universal Style Tags）

```
in the style of David Lynch, dark thriller film still,
surreal dark red, velvet texture, dream blue and gold,
surreal mood, dream logic,
cinematic film grain, moody atmosphere
```

## 二、人物肖像模板

### 模板 A：主角肖像

```

surreal dark red shadows with warm gold/neon blue highlights,
```

## 六、参数速查

| 效果 | 参数 |
|------|------|
| 电影感最强 | `--s 750 --style raw --v 6` |
| 更写实/更低干预 | `--s 250 --style raw --v 6` |
| 更艺术化 | `--s 900 --v 6` |
| 宽银幕电影 | `--ar 16:9` |
| 肖像竖版 | `--ar 3:4` |
| IMAX 宽屏 | `--ar 2.35:1` |
| 超现实氛围 | 提示词中加 `超现实暗红, 梦境逻辑` |
