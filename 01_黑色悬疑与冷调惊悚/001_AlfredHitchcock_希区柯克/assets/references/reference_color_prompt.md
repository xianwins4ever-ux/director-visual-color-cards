- 视觉定义：优雅中性色被翠绿和警示红刺破，颜色成为欲望与危险的开关。
- 光线：古典布光加入动机明确的色光；肤色保持可读，不让环境偏色吞没面部层次。
- 构图与摄影：空间—视线—目标—反应，精准推近；先交代颜色承载的空间，再进入人物与关键物件。
